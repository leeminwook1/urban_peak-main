# Urban Peak 리디자인

프로젝트 위치: `/Users/yun-eunseon/dev/urbanpeak1`

## 실행

Node.js 20 이상. 의존성은 `npm ci`로 설치합니다.

```sh
npm run build
npm run start -- --port 3100
```

브라우저에서 http://localhost:3100 을 엽니다. 개발 시 `npm run dev`를 사용합니다. 이 컴퓨터에서 파일 감시 제한 오류가 나면 `WATCHPACK_POLLING=true npm run dev`를 사용합니다.

## 이번 수정: White Desert 레이아웃 · 인터랙션

2026.11.13의 추가 요청에 따라 기존 첫 시안을 교체했습니다. 참고 사이트의 실제 스크롤과 패널을 브라우저에서 확인한 뒤 다음 동작을 구현했습니다.

- 중앙의 작은 로고, 좌우 분리 메뉴, 스크롤 방향에 따라 숨김·등장하는 헤더, 확장 메뉴
- 화면 전체를 채우는 영상과 대형 로고, 스크롤에 따른 확대·흐림·화이트 페이드
- 세로 그리드, 한쪽으로 들여쓴 소개와 단어별 밝기 전환
- 5장의 프로젝트 이미지가 가로로 펼쳐지는 카드. 마우스·키보드·하단 선택 버튼을 지원
- 고정된 스튜디오 이미지의 크기 변화와 대형 타이틀
- 데스크톱에서는 세로 스크롤에 연결된 가로 역량 카드, 모바일에서는 직접 넘기는 가로 스냅 카드
- 오른쪽 고정 How we work 버튼과 배경 흐림을 동반하는 슬라이드 패널. Escape 닫기, 포커스 이동, 배경 스크롤 잠금 지원
- 큰 배경 이미지 위에 배치한 Studio / Projects / Crew 제목과 Contact 폼
- 원본과 비슷한 인상의 오픈 폰트 Cormorant Garamond를 영문 디스플레이에 사용. 원본 사이트의 독점 폰트를 복제하지 않았으며 한글은 Pretendard 유지. 출처: https://github.com/google/fonts/tree/main/ofl/cormorantgaramond (OFL 라이선스 포함)
- 동작 줄이기 설정에서는 고정 스크롤 연출을 일반 가로 스크롤로 대체

사진·영상·문구는 어반피크 자료를 사용합니다. 원본의 남극 사진, 여행 상품, 지도 좌표나 수상 정보는 가져오지 않았습니다. 화면의 동작과 배치를 옮겼으며 서로 다른 콘텐츠와 서체 때문에 픽셀 단위 동일성을 보장하지는 않습니다.

## 유지한 콘텐츠 · 기능 기준

- 첫 영상은 사용자가 첨부한 참고 이미지와 일치하는 hero-05입니다. 영상 12개와 흰색 원본 로고를 유지하며, 헤더는 이번 요청대로 White Desert의 좌우 분리·중앙 로고 구조로 교체했습니다.
- 큰 이미지와 타이포, 여백, 세로 그리드를 기준으로 구성했습니다. 블루 #315FAC와 딥그린 #23504B의 브랜드 에셋을 유지하며, 이번 요청에 따라 푸터는 원본과 같은 화이트 구성으로 바꿨습니다.
- Home / Studio / Projects / Crew / Contact. Merchandise는 푸터에 유지합니다. /story는 /studio로 영구 이동합니다.
- Leadership 5명과 5개 역량군·9개 파트, 작업 방식 5단계는 DOCX에서 추출했습니다.
- 공개 운영 사이트의 프로젝트 11건, 굿즈 2건, 섹션 1건과 원본 자료를 source-data에 보존했습니다. 기존 소스는 original-source에 보관하며 실제 앱에서는 실행하지 않습니다.
- 영상 12개를 원본 그대로 유지합니다. 첫 포스터 12장 + 대표 장면 12장을 추출했습니다. 두 비디오 요소만 준비하고 로딩된 다음 영상으로 교차 전환합니다. 모두 muted, playsInline, loop입니다. 재생 차단 시 포스터를 표시하고, 동작 줄이기 설정과 작은 일시정지 버튼을 지원합니다.
- 영상 프레임은 홈과 Studio의 분위기 이미지로만 사용했습니다. 프로젝트와의 연결이 확인되지 않은 프레임을 특정 프로젝트의 실제 결과물로 표기하지 않았습니다.

## 문의 기능 — 현재 상태

수신 예정 주소는 사용자 확인에 따라 urbanpeak2020@gmail.com을 유지합니다. 이메일 서비스는 추후 연결합니다.

현재 POST /api/contact는 입력 검증 후 `.private/inquiries/<uuid>.json`에 실제로 저장합니다. 이 폴더는 공개 경로 밖이며 Git/배포 압축에서 제외됩니다. 응답은 저장 성공과 발송 서비스 접수를 구별합니다. 화면 역시 이메일 미발송을 분명하게 표시합니다. 브라우저 저장에만 의존하는 시각적 완료 화면이 아닙니다.

`.env.example`을 `.env.local`로 복사한 뒤 RESEND_API_KEY, CONTACT_FROM(인증된 발신자), CONTACT_TO를 설정하면 Resend로 메일을 접수합니다. 이메일 제공자의 접수는 실제 수신함 도착을 보장하지 않습니다. 현재 실발송·수신 검증은 수행하지 않았습니다. 사용자 요청에 따라 서비스 연결은 남겨두었습니다.

실서비스는 CONTACT_STORAGE_DIR을 비공개 영구 볼륨에 지정해야 합니다. 임시 디스크 기반 서버리스 환경에서는 현재 파일 저장 방식을 그대로 사용하지 말고 영구 저장소로 교체하세요. 문의 열람용 공개 API는 제공하지 않습니다. 저장 파일의 접근과 보관·삭제는 운영자가 관리합니다.

## 확인이 필요한 원본 자료

- 시선의 거리 / 나의 독립의 종료·후속 작업 상태는 확인 중으로 표시했습니다.
- 나만하의 2026.06.13 / 2026.05.23 날짜 충돌은 확인 중으로 표시하고 원본은 보존했습니다.
- 주최 / 주관 / 제작팀 / 어반피크 담당 범위와 개인별 크레딧은 구분했습니다. 자료가 없는 부분은 확인 중으로 표시합니다.
- Crew 개인 프로필·경력·사진은 추가로 창작하지 않았습니다.
- 기존 Frequency 프로젝트의 /uploads/ 이미지 5개는 운영 사이트에서 접근되지 않습니다. source-data/missing-assets.json에 원본 경로를 보존했습니다. 해당 프로젝트는 이미지 확인 중으로 표시합니다. 시선의 거리도 원본 이미지가 없습니다.
- 제공된 로고는 PNG입니다. 원본 실루엣을 유지하여 색상 변형과 아이콘을 만들었으며, 벡터 원본이 없으므로 SVG 원본을 만들어냈다고 주장하지 않습니다. 흰색은 사용자가 요청한 히어로에 적용했습니다.
- Studio의 별도 ‘요청서 소개 문안’은 DOCX 안에 따로 제공되지 않아, 문서에 명시된 홈 소개 문구와 기존 사이트의 이야기만 사용했습니다.

로컬 프로젝트로 제작했으며 기존 운영 사이트에는 반영하지 않았습니다.
